# Country Information App

A small React app I built to learn about fetching data from APIs while studying at NOVI Hogeschool. It shows information about countries around the world using the REST Countries API.

## What's in here?

- View all countries with their flags and populations
- Countries are color-coded by continent (Europe = yellow, Asia = red, etc.)
- Search for a specific country to see more details

## Tech stack

- React 18
- Vite
- Axios
- REST Countries API

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173/
